# Ember & Oak — Restaurant Website

A modern and responsive restaurant website designed to help businesses attract customers, showcase their menu, and manage table reservations efficiently.

## Features
- Interactive menu with 4 categories
- Online table reservation system
- Admin dashboard for booking management
- Customer testimonials section
- Restaurant gallery showcase
- Fully responsive design

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Business Impact
This website helps restaurants improve their online presence, increase customer engagement, and simplify reservation management. The integrated reservation system makes table booking convenient for customers, while the admin dashboard helps staff efficiently manage booking requests.
